BPR-02 · Captura a WhatsApp

Subí una captura de tu gráfico. Se analizará esa imagen y se enviará el resultado a tu WhatsApp configurado, incluso si la conclusión es NO TRADE.

No se envía nada hasta que elijas una imagen y pulses el botón.

Importante: cada envío consume una llamada a la API de visión y puede tener costo. Este servicio solo comparte el análisis de la captura; no abre ni ejecuta operaciones. Si la imagen no muestra suficiente información, la conclusión será NO TRADE. No uses una captura vieja como si fuera el mercado actual.
